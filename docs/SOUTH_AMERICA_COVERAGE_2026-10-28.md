## 4. Actual GLED primary replacements

The [baseline member-level screen](south_america_gled_screen_2026-10-28.csv)
found no adequate whole-source replacement among existing South American intake
alternatives. A documented additional source was therefore sought and reviewed:
Ferraz Gerardi et al. (2025),
[A phylogenetic classification of the Je language family: Supplementary data](https://github.com/TGH-2020/Je_Phylogeny),
doi:10.5281/zenodo.15041553, related article doi:10.12688/openreseurope.19346.3.
The author's published supplement has an explicit CC BY 4.0 license. Its pinned
commit is 8f4f0a9a7b36ba4e3a9a15ba49b13056cfbbcf1e.

| Construction | Study profile forms added | Total forms before → after | Supported core before → after |
| --- | ---: | ---: | ---: |
| Xerénte | 120 | 39 → 159 | 36 → 71 |
| Xavánte | 107 | 47 → 154 | 35 → 61 |

The licensed study becomes primary for both. All **84 earlier GLED forms and
two existing Wiktionary supplements** remain separately attributed. GLED forms
are not transcribed by the new primary profile; their prior source-specific
cognacy remains unchanged. The [preservation ledger](south_america_coverage_2026-10-28_gled_preservation.csv)
records these explicit GLED admissions. Reduced primary dependence does not mean
deleting the older evidence.

The study's notation requires interpretation. Nikulin (2020), section 1.4,
pp.50–53, documents the Macro-Jê alphabet. Conservative exact-form profiles cover
only already explicit unambiguous symbols, retaining broad source values without
inventing surface allophones or predictable echo vowels. Ambiguous c/ĵ/j/r/y,
circumflex vowel values, slash alternatives, leading diacritics, missing data and
unsplit compounds remain held. Nasalization and length are retained with NFC
normalization. All 227 study forms are **profile**, not supplied-IPA status.
Raw source notation survives unchanged, with the original full row and checksum.
Xerénte CROSS is corrected to the traverse verb, rather than the geometric noun:
Nikulin (2020), printed p.453 (PDF p.477), glosses tbro as atravessar.

Every automatic study COGID/COGIDS remains raw provenance only. No accepted
expert or computed cognate judgments are emitted from those columns, and GLED
judgments are not transferred to the new forms. Attribution is dataset-level;
individual fieldwork authorship is not inferred from related publications.

## 5. A newly represented South American language: Ingain

Ingain, inga1254, is a distinct language-level catalog entry. The accepted
registry, configs and source aliases contain no previous Ingain construction.
The initial reviewed slice adds **24 profile forms / 22 concepts / 16 core
concepts** from the same licensed study source. Of 59 mapped candidate rows,
24 are admitted and 35 held. The modest initial coverage reflects actual evidence;
unresolved shielding alternatives such as m/b are not converted by choosing
one convenient reading.

[Identity screen](south_america_missing_languages_2026-10-28.csv): Tapayúna,
Parkatêjê, Pykobjê and Xikrin are dialect-level cases under already accepted
languages. They are not counted as additional languages in this batch. Named
sample admission would require its own explicit packet. NLS attribution and
Tangam redistribution blockers from earlier work remain unresolved.

## Reproduction and verification

The source manifest and authored 368-row review are tracked under
src/arcaverborum/data/je_original_source.json and je_original_review.csv.
Across Xerénte, Xavánte and Ingain, **251 mapped rows are admitted / 117 held**;
other original entries outside the mapped review slice are not imported.
The frozen original TSV SHA256 is recorded in the manifest and every form.
The materializer checks the original TSV, README and license hashes. It creates
proper CSVW/CLDF identities and preserves full row provenance without runtime
CLDF ecosystem dependencies. Exact-form profiles cannot generalize to unknown
forms or secondary sources.

On first installation:

```bash
python scripts/stage_je_original.py --fetch --write-profiles
python scripts/append_source_intake.py --staged raw/curation/je-stage/lexibank
python scripts/append_source_intake.py --staged raw/curation/je-stage/lexibank --write
python build.py intake-db
python build.py update nub-xerente nub-xavante nub-ingain
```

Only the new gerardije2025 namespace was appended. Never append an existing
namespace or subset-ingest over active intake; later source changes require a
guarded migration. Generic fetching materializes the frozen source instead of
pulling a moving branch. Intake now has 7,181,640 rows. See the twelve updated
per-variety packets and recipes for the accepted construction details.

Verification: **408 tests pass**, full Ruff and JavaScript syntax checks pass;
all 7,314 accepted outputs are fresh with zero failures. Core-pilot and Vakh
audits pass. All **1,922 earlier records** in the eleven expanded constructions
retain lexical, transcription, concept and cognacy evidence; the two replaced
constructions have expected annotation/score/tier changes. All 400 compressed
artifact hashes validate. Generic and mixed-source browser checks cover exports,
provenance, profile isolation, retained GLED forms and the new Ingain page.
