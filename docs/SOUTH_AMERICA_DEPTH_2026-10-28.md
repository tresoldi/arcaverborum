## Safe expansion of an existing source namespace

The Jê namespace expands **251 → 371 forms**, **3 → 5 members**, with33 new
source parameters. This is an additive curation expansion of the same frozen
source, not an unreviewed upstream refresh. The new
scripts/expand_source_intake.py validates the complete staged namespace:

* Every earlier form, language and parameter must match exactly; no removal or
  alteration is allowed.
* Citation, license, source version and bibliography must remain unchanged.
* The caller supplies the expected old form count, and metadata counts must
  match the expanded tables.
* Default validates without writing. Writes preserve earlier table bytes,
  replace only the source's count metadata, and roll back failed replacements.

The authored review, source manifest and reference hashes are tracked under
src/arcaverborum/data/je_original_*. Profiles are exact whole-form mappings;
unknown forms and other sources cannot inherit the new rules.

For this specific migration from the preceding accepted baseline:

```bash
python scripts/stage_je_original.py --write-profiles
python scripts/expand_source_intake.py --staged raw/curation/je-stage/lexibank \
  --dataset gerardije2025 --expected-old-forms 251
python scripts/expand_source_intake.py --staged raw/curation/je-stage/lexibank \
  --dataset gerardije2025 --expected-old-forms 251 --write
python build.py intake-db
python build.py update nub-panara nub-apinaye nub-ingain
```

Never subset-ingest active intake, append an existing namespace as new, or repeat
this251-row migration after it has succeeded. Fresh installations can materialize
and append the complete new namespace before acceptance, as documented previously.
The intake database now has7,181,760 rows.
