# Worldwide proposal after reviewed source preference WS

Planning only; no lexical admissions authorized by the request for recommendations.
Baseline:7,338 constructions,2,071,777 records,469,321 supported core slots and1,569
GLED primaries. Accepted counts are from the committed catalog/WS metrics.

[Refreshed additive ranking](worldwide_after_ws_opportunities_2026-10-29.json):6,804 overlapping member opportunities,602 South American/904 American. These are not unique gains; older holds remain excluded from immediate admissions.

The recommendation is to combine bounded supplied-IPA upgrades with dictionary
profiles and a reserved genuinely missing-language search. Source migrations alone
do not increase language diversity. Raw candidate records below overlap existing
coverage and are not verified gains; all exact senses/member/stages remain gates.

provenance and an orthographic-symbol/IPA account, useful starting evidence for
source-specific profiles rather than invented conversion rules. Terms and actual
notation must still be checked dictionary by dictionary.

bounded reviewed task, not a promise to admit every candidate. Measure new records,
new supported slots, source preference changes and genuinely new languages separately.
