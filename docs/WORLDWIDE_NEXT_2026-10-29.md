Teop explicitly describes coastal-dialect orthographic headwords, including MWEs
and clitics; dictionary access does not itself establish IPA. Wanukaka distinguishes
regional varieties; Palula's Ashret/Biori contexts need source-level reconciliation.
Before intake, acquire an immutable export, verify its own redistribution terms,
read its notation guide and author exact sense/reading decisions. No conversion
or new-source intake has happened in this investigation.

[Lexibank](https://lexibank.clld.org/) is useful for release discovery and comparing
upstream dataset coverage; it is not independent corroboration of datasets already
represented. Check original sources and version changes instead of importing an
aggregate again. PHOIBLE-style inventories can check plausibility but cannot supply
word-specific pronunciations or lexical senses.

## Missing languages versus missing readings

The read-only SQLite screen groups existing lexical rows by source/member/code and
compares catalog canonical codes against Glottolog language-level entries. It finds
40 absent-code members, recorded in [the provisional screen](worldwide_absent_code_screen_2026-10-29.csv).
This is deliberately **not** a list of40 missing languages: `gled_MOMI` is a known
false positive because the accepted Momi construction now uses Vere Kaadam while
retaining its old source code. Other aliases, historical samples and source routes
have not yet been reconciled. Czech Sign Language is outside this spoken-IPA
pipeline. Broome Pearling Lugger Pidgin has15 raw rows; most other entries have1–2,
which is inadequate evidence for a substantial new-language batch. External
original-source acquisition is the promising route to real breadth.
