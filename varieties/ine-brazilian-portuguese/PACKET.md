# Brazilian Portuguese — scoped pronunciation supplementation

Primary IECOR forms and judgments are retained. The reviewed supplement adds 34
supplied IPA variants for 21 source translation forms/concepts, with exact
Wiktextract tag `Brazil`, original Wiktionary source-form IDs, stable pronunciation
IDs, raw IPA, source entry lines and the frozen dump hash. Phonemic and phonetic
representations remain separate. Narrower regional/register tags are not pooled;
every matched lemma/POS homograph must supply valid evidence for this scope.

The source-parent code port1283 is linked to target braz1246 only through the
explicit scope registry; unqualified general Portuguese evidence does not acquire
a Brazilian label. English-sense review is distinct from native lexical accuracy.
The named dictionary source remains Wiktionary, including its etymology namespace;
no IECOR cognate judgments are copied onto supplemental forms.

The cached IECOR language table explicitly places Brazilian Portuguese off
Portugal for map framing. That point is not a real sample location. Inherited
catalog coordinates are also suppressed, and the construction's macroarea is
South America. Actual sample coordinates remain unrecorded.

Core source collection membership is evaluated per lexical row: supplemental
Wiktionary material is visible under All accepted, and is not admitted to Core.
